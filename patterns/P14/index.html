01

Pointcut

Where the mechanism applies. All four dimensions belong to the proposed match, not just its vocabulary.

Context
Conversation state is derived from recorded events.
Trigger
A new event is appended or history is loaded.
Structure
Event schema, sequence or identity rules, and a projector.
Effect
The current view is reproducible from the event history.
02

Protected contract

The obligation that clients, operators, and auditors should be able to rely on.

Requires
Events are immutable enough to replay and schema versions are identifiable.
Ensures
Applying the same ordered events yields the same semantic state.
Invariant
Projection never mutates historical event identity.
Violation
Missing, incompatible, or corrupt events produce recoverable migration or rejection.

Negative control

A mutable message array without projection semantics is insufficient.

03

Variation & lifecycle

The hot spot is admitted only where the protected semantics survive.

Permitted variation

Event type unions, snapshots, migrations, local or remote persistence.

Test obligation

Test full replay, snapshot-plus-tail replay, schema evolution, and partial history.

Evolution question

Did conversation state move behind an append-and-project boundary?
