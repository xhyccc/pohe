01

Pointcut

Where the mechanism applies. All four dimensions belong to the proposed match, not just its vocabulary.

Context
A consumer observes an agent run incrementally.
Trigger
The runtime emits a semantic event or streamed token.
Structure
Async yield/resume, cancellation, and cleanup ownership.
Effect
Consumers receive ordered events and early exit releases runtime resources.
02

Protected contract

The obligation that clients, operators, and auditors should be able to rely on.

Requires
The producer exposes an async iterator or equivalent streaming boundary.
Ensures
Each emitted event has a stable type and sequence context.
Invariant
Cancellation and producer failure do not leave unreleased work.
Violation
Abandoned consumers trigger cancellation or documented cleanup.

Negative control

A synchronous list returned at the end is not the streaming pointcut.

03

Variation & lifecycle

The hot spot is admitted only where the protected semantics survive.

Permitted variation

Stream event schema, backpressure, buffering, and consumer adapters.

Test obligation

Test event order, consumer cancellation, producer exception, and cleanup.

Evolution question

Did streaming become a first-class typed event surface?
