03

Pointcut

Where the mechanism applies. All four dimensions belong to the proposed match, not just its vocabulary.

Context
An agent proposes a shell command with security-relevant structure.
Trigger
The command is about to be parsed, classified, or executed.
Structure
Shell parser, normalized command tree, policy evaluator, and execution handoff.
Effect
Authorization uses parsed operations and a parse failure cannot fall through to execution.
04

Protected contract

The obligation that clients, operators, and auditors should be able to rely on.

Requires
The command is representable by a parser or rejected before execution.
Ensures
Every subcommand and redirection is covered by a policy decision.
Invariant
Parsed intent and executed command refer to the same normalized operation.
Violation
Unsupported syntax fails closed or requests explicit review.

Negative control

A substring denylist is not syntax-aware permissioning.

05

Variation & lifecycle

The hot spot is admitted only where the protected semantics survive.

Permitted variation

Tree-sitter or shell AST, policy language, command aliases, and escalation.

Test obligation

Test pipes, substitutions, quoting, malformed input, and policy bypass attempts.

Evolution question

Did policy move from string matching to parsed operation boundaries?

06

Prompt + code design

An illustrative prompt and a small design sketch for the proposed contract. Names and APIs are invented; this is not a repository excerpt.

PROMPT SKETCH
Parse shell commands before execution. Every subcommand, pipeline stage, and redirection must receive a policy decision; if the command cannot be parsed, reject it rather than guessing.
CODE DESIGN / PYTHON
def authorize(command, policy):
    try:
        tree = shell_parser.parse(command)
    except ParseError:
        return Decision.deny("unparseable command")
    decisions = [policy.decide(node) for node in walk(tree)]
    if any(decision.denied for decision in decisions):
        return Decision.deny(decisions)
    return Decision.allow(decisions)

Illustrative design sketch. String matching on the full command cannot cover every nested effect. This example is a teaching aid, not implementation evidence or a conformance claim.
