01

Pointcut

Where the mechanism applies. All four dimensions belong to the proposed match, not just its vocabulary.

Context
A tool or environment can emit output larger than the context allowance.
Trigger
Output crosses a size or token cap.
Structure
Limit policy, truncation metadata, and access to complete artifacts.
Effect
The harness returns a bounded observation with explicit recovery information.
02

Protected contract

The obligation that clients, operators, and auditors should be able to rely on.

Requires
Output size is measurable and original content remains addressable.
Ensures
The consumer knows truncation occurred and can seek the full result.
Invariant
Truncation never masquerades as complete evidence.
Violation
Oversized or unavailable output returns a typed remediation error.

Negative control

A logging length limit unrelated to agent observations does not count.

03

Variation & lifecycle

The hot spot is admitted only where the protected semantics survive.

Permitted variation

Character, line, token, structure-aware caps, summaries, and repair hints.

Test obligation

Test exact limit, over-limit, non-UTF8, complete-artifact retrieval, and retry.

Evolution question

Did remediation become a typed contract rather than only text truncation?
