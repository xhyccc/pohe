06

Prompt + code design

An illustrative prompt and a small design sketch for the proposed contract. Names and APIs are invented; this is not a repository excerpt.

PROMPT SKETCH
Watch for repetition using evidence you can name: repeated actions, near-identical observations, or a declared semantic signal. Attribute any intervention to that evidence and record it in the trace.
CODE DESIGN / PYTHON
def detect_loop(history, policy):
    window = history[-policy.window :]
    if action_repetition(window) >= policy.action_threshold:
        return Intervention("repeated action", window[-1].action)
    if observation_similarity(window) >= policy.similarity_threshold:
        return Intervention("similar observations", window[-1].observation)
    return None

Illustrative design sketch. A loop detector without a recorded reason is indistinguishable from a random nudge. This example is a teaching aid, not implementation evidence or a conformance claim.
