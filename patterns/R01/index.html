03

Pointcut

Where the mechanism applies. All four dimensions belong to the proposed match, not just its vocabulary.

Context
An agent can reason and use an external action interface.
Trigger
The model emits reasoning followed by an action request.
Structure
Parsed action, execution result, and observation fed into the next cycle.
Effect
External evidence enters the reasoning trajectory before the next action.
04

Protected contract

The obligation that clients, operators, and auditors should be able to rely on.

Requires
Action and observation schemas are stable enough to parse.
Ensures
Every executed action has an attributable observation or execution error.
Invariant
Model reasoning is not treated as environment evidence.
Violation
Invalid action, unavailable tool, or parse error is exposed to the loop.

Negative control

Chain-of-thought text without external action is not ReAct.

05

Variation & lifecycle

The hot spot is admitted only where the protected semantics survive.

Permitted variation

Prompt protocol, typed tool call, XML or text parser, and observation compression.

Test obligation

Test action-observation linkage, malformed action, tool error, and loop termination.

Evolution question

Did textual thought-action protocols become typed tool events?

06

Prompt + code design

An illustrative prompt and a small design sketch for the proposed contract. Names and APIs are invented; this is not a repository excerpt.

PROMPT SKETCH
Interleave reasoning and action through a parseable protocol. Every executed action must have an attributable observation or an execution error; unparsed output is not an action.
CODE DESIGN / PYTHON
def reason_act(task, model, tools):
    trace = []
    while not trace or trace[-1].kind != "final":
        raw = model.complete(task, trace)
        step = protocol.parse(raw)
        if step.kind == "action":
            try:
                observation = tools.execute(step.action)
            except ToolError as error:
                observation = Observation.error(step.action, error)
            trace.append(observation)
        else:
            trace.append(step)
    return trace

Illustrative design sketch. The parser is the boundary between thought and effect; every effect gets an observation. This example is a teaching aid, not implementation evidence or a conformance claim.
