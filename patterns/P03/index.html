03

Pointcut

Where the mechanism applies. All four dimensions belong to the proposed match, not just its vocabulary.

Context
A harness run may pause for external work or user input.
Trigger
An event requests suspension or arrives to resume a paused run.
Structure
Enumerated states, legal transitions, event identity, and resumption state.
Effect
A resumed run follows only the legal transition and preserves durable state.
04

Protected contract

The obligation that clients, operators, and auditors should be able to rely on.

Requires
State can be serialized or retained and incoming events can be identified.
Ensures
Accepted events move the machine to a defined state and duplicate events are handled.
Invariant
No transition crosses from a disallowed state or executes twice after replay.
Violation
Invalid, duplicate, or interrupted events leave a recoverable state or raise explicitly.

Negative control

An enum without transition enforcement is not sufficient.

06

Prompt + code design

An illustrative prompt and a small design sketch for the proposed contract. Names and APIs are invented; this is not a repository excerpt.

PROMPT SKETCH
Treat a paused run as an explicit state, not a sleeping function. Persist the state token before waiting, accept only known events, and reject duplicate or illegal transitions with a typed error.
CODE DESIGN / PYTHON
TRANSITIONS = {
    "ready": {"start": "running"},
    "running": {"wait": "waiting", "finish": "done"},
    "waiting": {"resume": "running", "cancel": "cancelled"},
}

def apply(state, event, store):
    target = TRANSITIONS.get(state.status, {}).get(event.kind)
    if target is None:
        raise IllegalTransition(state.status, event.kind)
    next_state = state.with_status(target, event_id=event.id)
    store.save(next_state)
    return next_state

Illustrative design sketch. The durable record, not an in-memory coroutine, is the resumable unit. This example is a teaching aid, not implementation evidence or a conformance claim.
