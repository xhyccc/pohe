01

Pointcut

Where the mechanism applies. All four dimensions belong to the proposed match, not just its vocabulary.

Context
A harness run may pause for external work or user input.
Trigger
An event requests suspension or arrives to resume a paused run.
Structure
Enumerated states, legal transitions, event identity, and resumption state.
Effect
A resumed run follows only the legal transition and preserves durable state.
02

Protected contract

The obligation that clients, operators, and auditors should be able to rely on.

Requires
State can be serialized or retained and incoming events can be identified.
Ensures
Accepted events move the machine to a defined state and duplicate events are handled.
Invariant
No transition crosses from a disallowed state or executes twice after replay.
Violation
Invalid, duplicate, or interrupted events leave a recoverable state or raise explicitly.

Negative control

An enum without transition enforcement is not sufficient.

03

Variation & lifecycle

The hot spot is admitted only where the protected semantics survive.

Permitted variation

Transition dispatch, persistence backend, and recovery policy.

Test obligation

Test illegal transitions, duplicate events, interruption, and resume.

Evolution question

Did implicit control flow become an observable durable state machine?
