Pointcut

Where the mechanism applies. All four dimensions belong to the proposed match, not just its vocabulary.

Context
A harness surrounds model or tool invocation with extensible behavior.
Trigger
A call enters or leaves the runtime boundary.
Structure
Ordered middleware entries with a continuation or short-circuit result.
Effect
Logging, policy, retry, or context behavior runs in declared order.
04

Protected contract

The obligation that clients, operators, and auditors should be able to rely on.

Requires
The boundary exposes a composable continuation contract.
Ensures
Middleware executes in deterministic order and the final result reaches the loop.
Invariant
A middleware does not silently bypass required downstream layers.
Violation
Short circuits and exceptions unwind deterministically with one terminal result.

Negative control

A hard-coded helper call is not a middleware pipeline.

Prompt + code design

An illustrative prompt and a small design sketch for the proposed contract. Names and APIs are invented; this is not a repository excerpt.

PROMPT SKETCH
Apply model and tool calls through an ordered middleware chain. Each layer may inspect, annotate, redact, or reject a call, but the final handler must see the composed result exactly once.
CODE DESIGN / PYTHON
def compose(layers, handler):
    call = handler
    for layer in reversed(layers):
        call = layer(call)
    return call

pipeline = compose(
    [trace_calls, redact_secrets, enforce_budget, retry_transient],
    invoke_model,
)
result = pipeline(request)

Illustrative design sketch. Order is part of the contract; record the resolved chain with the result. This example is a teaching aid, not implementation evidence or a conformance claim.
