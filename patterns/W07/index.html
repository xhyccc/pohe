03

Pointcut

Where the mechanism applies. All four dimensions belong to the proposed match, not just its vocabulary.

Context
Multiple peer agents can transfer control.
Trigger
The active agent invokes a handoff target.
Structure
Control-transfer envelope, state policy, target criteria, and authority boundary.
Effect
The target becomes active with declared history and no implicit privilege expansion.
04

Protected contract

The obligation that clients, operators, and auditors should be able to rely on.

Requires
Target identity and transfer trigger are explicit.
Ensures
Handoff records source, target, and transferred state.
Invariant
Control cannot cycle indefinitely or return to an invalid target.
Violation
Unknown targets, disabled handoffs, and loops have defined outcomes.

Negative control

A normal function call that returns to the caller is not a handoff.

06

Prompt + code design

An illustrative prompt and a small design sketch for the proposed contract. Names and APIs are invented; this is not a repository excerpt.

PROMPT SKETCH
Hand off control only with an explicit target and trigger. Record the source, target, and transferred state, and enforce a cycle bound so a peer conversation can terminate.
CODE DESIGN / PYTHON
def handoff(session, target, trigger, state):
    if session.handoff_count >= session.max_handoffs:
        raise HandoffLimit(session.id)
    record = HandoffRecord(
        source=session.active_agent,
        target=target,
        trigger=trigger,
        state=state.redact_for(target),
    )
    session.apply(record)
    return target.resume(session)

Illustrative design sketch. A transfer without state or a cycle bound is an unbounded conversation, not coordination. This example is a teaching aid, not implementation evidence or a conformance claim.
