Pointcut

Where the mechanism applies. All four dimensions belong to the proposed match, not just its vocabulary.

Context

Trigger
A remote client invokes the adapter or a hosted backend is selected.

06

Prompt + code design

An illustrative prompt and a small design sketch for the proposed contract. Names and APIs are invented; this is not a repository excerpt.

PROMPT SKETCH
Expose the harness through a declared compatibility protocol. Map capabilities explicitly, return protocol-shaped errors, and reject requests that the backend cannot satisfy.
CODE DESIGN / PYTHON
def handle(request, backend, protocol):
    if not protocol.supports(request.method):
        return protocol.error("method_not_supported", request.id)
    try:
        result = backend.invoke(protocol.to_backend(request))
    except BackendError as error:
        return protocol.error(error.code, request.id, detail=error.detail)
    return protocol.from_backend(result)

Illustrative design sketch. Compatibility is a contract over requests, results, and errors, not a renamed endpoint. This example is a teaching aid, not implementation evidence or a conformance claim.
