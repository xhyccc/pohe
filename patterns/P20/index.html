01

Pointcut

Where the mechanism applies. All four dimensions belong to the proposed match, not just its vocabulary.

Context
An attempt can be evaluated before a further attempt.
Trigger
The attempt fails or receives a critique.
Structure
Attempt record, feedback producer, revision input, and retry bound.
Effect
A revised attempt uses recorded feedback while preserving attempt lineage.
02

Protected contract

The obligation that clients, operators, and auditors should be able to rely on.

Requires
Failure evidence and remaining retry budget are available.
Ensures
Feedback is attached to the attempt that produced it and is visible to revision.
Invariant
Self-critique is not represented as independent verification.
Violation
Empty, contradictory, or exhausted feedback terminates or escalates.

Negative control

A static system prompt asking the model to reflect is not enough.

03

Variation & lifecycle

The hot spot is admitted only where the protected semantics survive.

Permitted variation

Self-critique, external evaluator, memory injection, and iterative refinement.

Test obligation

Test useful feedback, contradictory feedback, exhaustion, and repeated error.

Evolution question

Did reflection add independent evaluation and bounded convergence?
