01

Pointcut

Where the mechanism applies. All four dimensions belong to the proposed match, not just its vocabulary.

Context
Harness behavior is assembled from independently typed components.
Trigger
Components are selected, composed, or replaced.
Structure
Component interface, composition builder, evaluator, and artifact registry.
Effect
The built harness is executable and its component provenance is recoverable.
02

Protected contract

The obligation that clients, operators, and auditors should be able to rely on.

Requires
Components have compatible contracts and composition operators.
Ensures
Invalid composition is rejected before execution.
Invariant
Reusing a component does not silently reuse privileged state.
Violation
Build conflicts, incompatible versions, and evaluation failure are explicit.

Negative control

Separate helper functions without component contracts are insufficient.

03

Variation & lifecycle

The hot spot is admitted only where the protected semantics survive.

Permitted variation

Typed processors, foundry DSL, component search, and immutable builders.

Test obligation

Test composition, incompatible component, rebuild, and provenance.

Evolution question

Did composition move from code edits to a searchable component space?
