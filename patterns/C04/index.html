Pointcut

Where the mechanism applies. All four dimensions belong to the proposed match, not just its vocabulary.

Context
A caller invokes a service or provider without direct construction.
Trigger
A service description is registered or a request is addressed.
Structure
Registry, service description, transport, request/reply, and error mapping.
Effect
Broker resolves a compatible endpoint and returns a correlated response.
04

Protected contract

The obligation that clients, operators, and auditors should be able to rely on.

Requires
Provider identity and versioned service description are available.
Ensures
Client and provider agree on schema or return incompatibility.
Invariant
Broker discovery does not bypass authentication or trust boundaries.
Violation
Provider absence, timeout, partial reply, and schema mismatch are explicit.

Negative control

06

Prompt + code design

An illustrative prompt and a small design sketch for the proposed contract. Names and APIs are invented; this is not a repository excerpt.

PROMPT SKETCH
Resolve a provider by identity and versioned service description. The client and provider must agree on the schema or return an explicit incompatibility, never a guessed call.
CODE DESIGN / PYTHON
def invoke(service_id, request, registry):
    provider = registry.resolve(service_id)
    if provider is None:
        return Incompatible(service_id, reason="not registered")
    if not provider.schema.accepts(request):
        return Incompatible(service_id, reason="schema mismatch")
    return provider.call(request)

Illustrative design sketch. Discovery without schema agreement is a lookup, not a broker contract. This example is a teaching aid, not implementation evidence or a conformance claim.
