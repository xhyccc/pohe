03

Pointcut

Where the mechanism applies. All four dimensions belong to the proposed match, not just its vocabulary.

Context
Multiple specialized agent or tool paths are available.
Trigger
New input must be sent to a destination.
Structure
Route schema, classifier or rules, dispatch result, and unsupported case.
Effect
One route is selected and its decision is attributable to input evidence.
04

Protected contract

The obligation that clients, operators, and auditors should be able to rely on.

Requires
Routes have declared capabilities and selection criteria.
Ensures
The selected route can handle the input or returns unsupported.
Invariant
Dispatch never loses the original request or silently invokes multiple exclusive routes.
Violation
Classifier error or ambiguous route has deterministic fallback or escalation.

Negative control

An if statement inside one prompt is not an observable routing contract.

06

Prompt + code design

An illustrative prompt and a small design sketch for the proposed contract. Names and APIs are invented; this is not a repository excerpt.

PROMPT SKETCH
Select a route by declared capabilities and selection criteria. If no route can handle the input, return unsupported rather than silently falling back to a generic answer.
CODE DESIGN / PYTHON
def route(request, routes):
    candidates = [route for route in routes if route.can_handle(request)]
    if not candidates:
        return Unsupported(request.kind)
    chosen = max(candidates, key=lambda route: route.confidence(request))
    return chosen.dispatch(request)

Illustrative design sketch. Routing evidence is the selected route's capability, not the router's confidence alone. This example is a teaching aid, not implementation evidence or a conformance claim.
