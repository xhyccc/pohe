Routing

Select a specialized path for an input.

01

Pointcut

Where the mechanism applies. All four dimensions belong to the proposed match, not just its vocabulary.

Context
Multiple specialized agent or tool paths are available.
Trigger
New input must be sent to a destination.
Structure
Route schema, classifier or rules, dispatch result, and unsupported case.
Effect
One route is selected and its decision is attributable to input evidence.
02

Protected contract

The obligation that clients, operators, and auditors should be able to rely on.

Requires
Routes have declared capabilities and selection criteria.
Ensures
The selected route can handle the input or returns unsupported.
Invariant
Dispatch never loses the original request or silently invokes multiple exclusive routes.
Violation
Classifier error or ambiguous route has deterministic fallback or escalation.

Negative control

An if statement inside one prompt is not an observable routing contract.

03

Variation & lifecycle

The hot spot is admitted only where the protected semantics survive.

Permitted variation

LLM router, rules, handoff tool, nested graph, and default route.

Test obligation

Test each route, ambiguous input, unsupported input, and selection cost.

Evolution question

Did routing gain explicit alternatives and error handling?
