03

Pointcut

Where the mechanism applies. All four dimensions belong to the proposed match, not just its vocabulary.

Context
A lead agent can generate tasks rather than call a fixed pipeline.
Trigger
The orchestrator decomposes a goal or dispatches a subtask.
Structure
Task plan, worker selection, delegation envelope, and synthesis step.
Effect
Synthesized output accounts for generated task results and delegated authority.
04

Protected contract

The obligation that clients, operators, and auditors should be able to rely on.

Requires
Workers advertise capabilities and share a task/result protocol.
Ensures
Every dispatched task has a result or failure and the final answer links them.
Invariant
Dynamic dispatch cannot create unbounded uncounted worker expansion.
Violation
Unsplittable, failed, or duplicate work is reflected in synthesis.

Negative control

A fixed sequence of sub-agents is W01 rather than dynamic W04.

06

Prompt + code design

An illustrative prompt and a small design sketch for the proposed contract. Names and APIs are invented; this is not a repository excerpt.

PROMPT SKETCH
Decompose the task into worker-sized units, dispatch each with a task record, and require a result or failure for every dispatched task before composing the answer.
CODE DESIGN / PYTHON
def orchestrate(task, workers):
    tasks = planner.decompose(task)
    pending = {item.id: workers.dispatch(item) for item in tasks}
    results = {}
    for task_id, handle in pending.items():
        results[task_id] = handle.result_or_failure()
    if any(isinstance(result, Failure) for result in results.values()):
        return PartialResult(results)
    return composer.compose(results)

Illustrative design sketch. Dynamic decomposition is bounded by the result ledger, not by the planner's confidence. This example is a teaching aid, not implementation evidence or a conformance claim.
